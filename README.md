# 🟢 KickSync - Discord Rich Presence for Kick

**Welcome to KickSync!** 
KickSync is a lightweight, easy-to-use desktop app that instantly connects your Kick.com stream to your Discord profile. Let your friends, community, and Discord servers know exactly when you are live, what game you are playing, and how long you have been streaming.

## ✨ Why use KickSync?

* **Live API Sync:** Simply click a button and KickSync will automatically pull your current stream title and category directly from Kick.
* **Manual Override:** Don't want to sync automatically? You can manually type in a custom stream title and category to display on your Discord profile.
* **Custom Artwork:** Upload your own personal logo or branding to show on your Discord status, or use the sleek default Kick logo.
* **Zero Lag:** Built to be incredibly lightweight, ensuring it uses virtually zero system resources while running in the background while you game.
* **Live Preview:** See exactly what your Discord status will look like inside the app before you push it live.

## 🚀 How to Download & Install

1. Go to the [Releases Page](../../releases/latest) on the right side of this screen.
2. Download the latest **`KickSync_Setup.exe`** file under the "Assets" section.
3. Run the installer and follow the quick setup wizard.
4. Launch KickSync from your Start Menu!

## 🎮 How to Use

1. **Connect:** Open the app and enter your Kick username.
2. **Choose your Source:** 
   * Select **Live API Sync** to automatically pull your data from Kick.
   * Select **Manual Override** to type in your own title and category.
3. **Choose your Art:** Use the default logo or upload a custom image from your PC.
4. **Go Live:** Click the big **Push Status to Discord** button.

*That's it! Anyone who clicks your name in Discord will now see your live stream details.*

## ⚠️ Troubleshooting

**My status isn't showing up on Discord!**
* Make sure the Discord Desktop app is open and running on your PC. (Browser versions of Discord do not support Rich Presence).
* Open your Discord User Settings > **Activity Privacy** and make sure **"Display current activity as a status message"** is turned ON.

**The Live API Sync says "Awaiting Data"**
* Make sure you are actually live on Kick! The API will only pull your title and category if your stream is actively broadcasting.
